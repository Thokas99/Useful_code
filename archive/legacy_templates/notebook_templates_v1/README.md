# Legacy notebook templates

This superseded scaffold is preserved for history. Use the active
[analysis guides](../../../templates/).

The notebooks are configurable starting points, not study results. They expect
explicit inputs, identifiers, and output paths; package versions and analysis
choices must be recorded with any copied workflow. The files have not all been
run against representative data.

| Family | Former scope |
|---|---|
| `scRNA/` | Seurat setup, QC, clustering, signatures, markers, trajectories, modules, velocity, activity |
| `scATAC/` | Signac setup, QC, LSI, and motifs |
| `multiome/` | Paired RNA/ATAC and linkage |
| `general_statistics/` | Group summaries and association tests |

These old templates preserve their original implementation. Their defaults do
not define study-specific parameters.
